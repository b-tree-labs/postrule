\section{Introduction}\label{introduction}

(Keep the ``every production codebase has classify functions''
motivation; drop product language.)

What is \emph{not} claimed as novel: LLM cost-cascades (FrugalGPT) and
learning-to-defer route between models already; paired-McNemar
classifier comparison is standard. What \emph{is} contributed: (1) a
characterization of which dataset characteristics predict the
cost-optimal tier, (2) an adaptive algorithm that exploits it to cut
labeled-data cost at parity accuracy, and (3) honest evidence on where a
learned cross-site policy does and does not work.

\subsection{Contributions}\label{contributions}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Aligned multi-tier benchmark} --- rule / zero-shot LLM /
  few-shot LLM / classical-ML-curve, all on one common test set per
  dataset, on a shared labeled-outcomes-consumed axis, across 19 text
  datasets (sentiment, intent, moderation, emotion, topic, spam) +
  preliminary image/audio.
\item
  \textbf{Predictive characterization} --- label cardinality (Spearman
  ρ≈−0.7 vs outcomes-to-graduate) and rule-over-chance predict which
  tier wins and how deep ML must train.
\item
  \textbf{AGA} --- chooses the terminal tier and graduates under a
  non-inferiority gate; matches fixed-ladder accuracy at
  \textasciitilde44\% fewer labeled outcomes.
\item
  \textbf{Two honest negatives} --- a learned cross-site tier-predictor
  does not generalize at 21 datasets; spectrogram-vision fails on audio.
  Plus a tunable non-inferiority (``close-enough'') gate for cost-aware
  graduation.
\end{enumerate}

\section{Setup}\label{setup}

\begin{itemize}
\tightlist
\item
  \textbf{Tiers.} RULE → MODEL (LLM, zero/few-shot) → ML (classical
  sklearn head). The LLM is the neural-net tier; ML is the trained
  classical tier.
\item
  \textbf{Datasets.} 19 text + CIFAR-10 (image) + ESC-50 (audio).
\item
  \textbf{Aligned protocol.} Common test subset per dataset (text
  n=400); rule from a 100-example seed; ML as a budget curve; LLM
  (Claude Haiku) zero- and few-shot (≤40 exemplars). Each tier placed at
  its true labeled-outcome cost (rule≈100, zero-shot=0, few-shot=k,
  ML=budget).
\item
  \textbf{Two costs.} We separate \textbf{one-time labeled-outcome cost}
  (to train ML / seed the rule) from \textbf{perpetual per-call
  inference cost} (the LLM bills every call forever; rule/trained-ML are
  \textasciitilde free per call). AGA's savings are reported on the
  labeled-outcome axis; the steady-state inference-cost argument is what
  makes graduating \emph{off} the LLM valuable.
\end{itemize}

\section{Adaptive Graduated Autonomy}\label{adaptive-graduated-autonomy}

\begin{itemize}
\tightlist
\item
  \textbf{oracle\_terminal} is \emph{multi-objective}, applied in
  priority order: (i) \textbf{modality feasibility} (hard filter ---
  e.g.~spectrogram-vision can't read words), (ii) \textbf{latency SLO}
  (hard --- a tier breaching the real-time budget is out), (iii)
  \textbf{accuracy} within a Wilson-CI significance band, (iv)
  \textbf{operating cost} minimized within the band (perpetual inference
  \$ + labeled cost). The LLM wins only when \emph{significantly} better
  on accuracy \emph{and} feasible within the latency/modality
  constraints; otherwise a rule/trained-ML tie graduates off the LLM.
  Cost is the axis this study measures; latency and modality are
  first-class and default to unconstrained.
\item
  \textbf{Tie-to-graduate}: ML graduates once it \emph{ties} the LLM
  (non-inferiority), not once it beats it.
\item
  \textbf{CostToleranceGate}: the non-inferiority gate; ε is
  operator-tunable.
\item
  \textbf{The router is permanent}: it holds the rule floor, watches for
  drift, and re-escalates to the LLM when the data demands --- only the
  LLM \emph{dependency} shrinks.
\end{itemize}

\subsection{Honest negative: cross-site prediction does not yet
generalize}\label{honest-negative-cross-site-prediction-does-not-yet-generalize}

A gradient-boosted predictor of the best tier from early-observable
characteristics scores \textbf{below the majority baseline}
leave-one-dataset-out at 21 datasets, and its apparent skill swings with
test-set noise (0.62→0.41 between n=200 and n=400 before
significance-aware labeling). \textbf{Conclusion: per-site measured
routing is what works today; cross-site prediction needs a much larger
fleet.} This is a finding, not a failure --- it tells practitioners to
measure, not guess.

\section{Preliminary: image and
audio}\label{preliminary-image-and-audio}

The gate is modality-agnostic (it consumes (decision, outcome) pairs);
only the LLM input path is modality-specific. Rule+ML transfer to
CIFAR-10 and ESC-50. The MODEL tier is preliminary: Claude vision on
CIFAR images reaches 0.78 zero-shot (but our pixel-logreg ML is a weak
baseline), and a spectrogram→vision proxy for ESC-50 \textbf{fails}
(0.017, below chance) --- native-audio models are needed. We report
these as preliminary evidence of modality-generality, not as headline
results.

\section{Limitations}\label{limitations}

\begin{itemize}
\tightlist
\item
  \textbf{Classical-ML baselines are the cheap day-N head} (TF-IDF /
  pixel / MFCC + logistic regression), not fine-tuned transformers. A
  stronger ML tier would shift some ``LLM wins,'' especially on image.
  Reported honestly; a fine-tuned-transformer ablation is future work.
\item
  \textbf{Single LLM (Claude Haiku), single prompt} --- accuracies are
  prompt/model sensitive.
\item
  \textbf{Multimodal MODEL tier is a proxy} (spectrogram/frames); native
  audio/video models are future work. Spectrogram-vision is shown to
  fail on environmental audio.
\item
  \textbf{Cross-site meta-prediction does not generalize} at this fleet
  size (§4.2).
\item
  \textbf{n=400 test subsets} → accuracy CIs ≈ ±0.04; we use
  significance-aware tie bands accordingly.
\end{itemize}

\section{Related work}\label{related-work}

FrugalGPT / LLM cascades (cost routing); learning-to-defer (per-example
deferral); champion-challenger + shadow deployment (MLOps); McNemar /
Dietterich. AGA differs by choosing the \emph{terminal} tier per stream
from characteristics and graduating off the LLM under a non-inferiority
gate --- not per-example routing or a hand-tuned cascade.
